# Changelog

All notable project changes are documented here.

## V2.0.0 — CYBER COMMAND

- Added a dark system diagnostics dashboard with consent-first scan categories.
- Added a Python standard-library server bound to `127.0.0.1`.
- Added Windows PowerShell diagnostic collectors for security, processes/network, startup, storage, RAM/CPU, system integrity, and browser extension metadata.
- Added separately consented live monitoring.
- Added a constrained repair center with quarantine, restore, eligible current-user startup disable, and separately confirmed permanent deletion for eligible files in Downloads/Temp.
- Added local diagnostic report export and synthetic sample report.
- Documented operating-system limitations, privacy boundaries, false-positive handling, and testing status.

This release is experimental. See README.md for validation status and limitations.
