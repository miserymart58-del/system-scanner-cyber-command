Owner-controlled actions

Smart repair center

Choose an exact item, inspect its path, then confirm that single action. Quarantine is reversible; permanent deletion is not. Cross-volume moves may need free space on the system drive.

Files are eligible only when they appear in the latest scan report and still match the scanned size/timestamp. Permanent deletion is limited to Downloads and Temp and requires typing DELETE PERMANENTLY. Current-user startup entries can be disabled and restored. For a Run-key restore, the full original registry value (which may include arguments) is saved locally only after you choose Disable startup. Windows services, security products, system files and arbitrary paths are not repair targets.

Items available for review

Run a scan with Storage, Processes and/or Startup selected to populate eligible items. Older Temp files may appear as optional cleanup candidates.
